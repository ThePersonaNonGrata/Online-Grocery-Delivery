README2.txt — Unit Testing

Purpose:
  This folder contains standalone unit tests for core cart logic:
    - add/remove items
    - change quantity
    - compute totals

Prerequisites:
  - Python 3.10+ installed

How to run:
  1) Open a terminal in this folder (2_unit_testing)
  2) Run:
       python -m unittest -v

Expected output:
  Tests should pass with an OK message.
