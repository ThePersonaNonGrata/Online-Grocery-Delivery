README4.txt — Data Collection

Purpose:
  This folder contains a script that generates sample JSON files for the demo.
  These can be used to preload products/users/orders for screenshots or demos.

Prerequisites:
  - Python 3.10+

How to run:
  1) Open a terminal in this folder (4_data_collection)
  2) Run:
       python generate_sample_data.py

Output files created in this folder:
  - sample_products.json
  - sample_users.json
  - sample_orders.json
